Personal website and portfolio of Aly Elalwany — software engineer building secure, scalable cloud platforms at SAP.

**[elalwany.de](https://elalwany.de)**

## What's on the site

- **About** — Background in cloud infrastructure, platform security, and high-throughput systems
- **Currently** — Work at SAP on AI infrastructure, the Application Vulnerability Report (AVR), GitOps pipelines, and open-source Crossplane Providers
- **Services** — AI adoption, cloud security, GitOps & IaC, event-driven systems, and cloud architecture
- **Coaching** — Engineering practices, AI maturity, and team scaling for software teams
- **Blog** — Technical writing on software engineering topics
- **Contact** — How to get in touch

## Tech Stack

- **[Astro](https://astro.build)** — Static site generator
- **TypeScript** — Type-safe JavaScript
- **Tailwind CSS** — Utility-first CSS framework
- **Jest** — Testing framework
- **ESLint** — Code linting
